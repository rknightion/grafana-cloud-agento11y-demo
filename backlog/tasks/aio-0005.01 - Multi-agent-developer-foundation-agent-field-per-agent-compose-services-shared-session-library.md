## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Every developer is assumed to be Claude Code: Terraform creates a Cognito user per developer, render.py gives every dev container the gateway dependency, managed settings and claude volumes, the gateway pushes the AGENTO11Y_* env, and dev-session/dev-loop/dev-reseed/entrypoint.sh are Claude-specific. Each new agent needs the same seams, so they are built once here and the agent tasks plug into them. This task owns agent-host/render/render.py, agent-host/SEAM.md, terraform/variables.tf, terraform/locals.tf, terraform/aws-cognito.tf and the shared parts of apps/dev-workstation (entrypoint.sh, bin/dev-loop, bin/dev-session); other subtasks of AIO-0005 add agent-specific pieces through it. render.py is in the host bundle, so its edits replace the host on apply: do not apply this alone, it ships in the single rollout (AIO-0005.08). See doc-0002 "Cross-cutting facts".
<!-- SECTION:DESCRIPTION:END -->
