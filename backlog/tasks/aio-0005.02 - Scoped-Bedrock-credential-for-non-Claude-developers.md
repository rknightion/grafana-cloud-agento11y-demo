## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Developer containers cannot reach IMDS (only the gateway can), and Codex and pi cannot use the Claude apps gateway, so they need their own Bedrock credential. The maintainer chose a scoped IAM principal in the agent-host secret, with no budgets, alarms or residency constraint. Codex uses OpenAI models on bedrock-mantle (action bedrock-mantle:CreateInference, possibly US-region only, which is acceptable); pi uses the existing per-team application inference profiles (data.aws_iam_policy_document.bedrock_invoke in terraform/aws-bedrock.tf). See doc-0002.
<!-- SECTION:DESCRIPTION:END -->
