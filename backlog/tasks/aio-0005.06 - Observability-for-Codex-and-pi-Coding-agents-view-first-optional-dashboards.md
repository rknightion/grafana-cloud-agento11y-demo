## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The Claude Code dashboard, alerts and recording rules are built on claude_code_* native metrics, which Codex and pi do not emit. The built-in Coding agents view covers sessions, cost, tokens and tools by agent and user, so it is the first-cut surface. Codex has native OTel worth panels (TTFT, API latency, hook runs); pi has only plugin metrics.
