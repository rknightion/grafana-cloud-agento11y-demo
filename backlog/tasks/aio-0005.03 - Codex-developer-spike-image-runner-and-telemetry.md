## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Adds OpenAI Codex CLI as a developer agent. doc-0002 "Codex" has the facts: amazon-bedrock provider on bedrock-mantle, hooks-based plugin with one generation per turn, managed hooks in /etc/codex/config.toml to avoid the interactive trust step the Grafana guide mentions, native OTel that needs logs:write, and several UNVERIFIED items. Start with a spike on a throwaway box (not the demo host) and record the answers in this task before building. The spike decides the Bedrock region and whether MCP works on the Bedrock provider; if MCP does not, record which prompts are excluded for Codex.
<!-- SECTION:DESCRIPTION:END -->
