## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The rules in terraform/grafana-agento11y.tf match only claude-code agent names and Claude tool names (Bash, Read, Edit, Write, Grep, WebFetch). Guard calls carry no tags, so rules scope by agent name only. Codex supports preflight deny; pi supports preflight transform but not deny, and sends lowercase tool names; Codex hosted tools such as WebSearch are not hooked. This task owns terraform/grafana-agento11y.tf and the guard-policy experiment suites. Priority order must keep deny rules below 10 (docs/security.md).
<!-- SECTION:DESCRIPTION:END -->
