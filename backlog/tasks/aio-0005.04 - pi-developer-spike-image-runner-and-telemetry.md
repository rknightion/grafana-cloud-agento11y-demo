## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Adds pi (earendil-works/pi, formerly pi-mono) as a developer agent with the @grafana/agento11y-pi extension. doc-0002 "pi" has the facts: built-in MCP since 0.99 (use exposure direct), in-process extension that exports per-turn generations with cost from pi's own catalog, preflight deny unsupported but preflight redaction supported, no permission system, and the stdin hang trap. A local spike on pi 1.2.0 with plugin 0.25.0 already verified print and JSON modes, export and postflight deny; the remaining spike is against real Bedrock profiles and the real stack.
